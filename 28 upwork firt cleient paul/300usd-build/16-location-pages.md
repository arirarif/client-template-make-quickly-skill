# 16 — Location pages (all nine, paste-ready)

The largest organic gain available, and the one thing on the list that is genuinely new scope.
**Quote it separately** — nine pages of original copy is a project, not a maintenance task.

**Why these pages exist.** Nobody searches "vacation rental photographer". They search
**"Airbnb photographer Siesta Key"**. Neither site has a page containing those words, so neither
can rank for them. Each page below targets a search that already exists and currently returns
competitors.

**Rules followed while writing.** Every claim traces to something already published on Paul's
sites — services, service areas, add-on pricing, that he shoots personally, that he is an investor
and Airbnb host. **No invented statistics, no invented client names, no claims about specific
neighbourhoods I could not verify.** Local detail is limited to geography that is a matter of public
record (that Siesta Key is a barrier island, that Anna Maria has a height limit on buildings, and so
on) — Paul should still read each page and correct anything that does not match his experience.

**Do not publish these as near-identical pages with the town name swapped.** Google treats that as
doorway pages and it can earn a penalty. Each page below has genuinely different content, a
different angle and a different reason to exist. Keep it that way.

**Per page, before publishing:**
- SEO title: `<Service> <Town> FL | <Brand>`
- Meta description: 140–155 characters, mentioning the town
- One H1 containing the town name
- Link to it from the Services page and from the footer service list
- Link out from it to two or three relevant service pages
