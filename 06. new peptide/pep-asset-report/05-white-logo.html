Step-by-step · How to wire it in

Deployment Recipe.

  1. Verify the files are actually white — open one in image editor, eyedrop a pixel. If #000, request real white variant from client first.
  2. Upload both PNGs to WP Media Library.
  3. Go to WoodMart → Theme Settings → Header → swap the logo for the WIDE lockup.
  4. Go to WoodMart → Theme Settings → Mobile Header → swap the mobile logo for the ATOM-ONLY variant.
  5. Go to Appearance → Customize → Footer Builder → swap the footer logo for the WIDE lockup.
  6. Go to WooCommerce → Settings → Emails → Header image → upload the WIDE lockup for transactional emails.
  7. Hard-refresh the site on desktop + mobile to verify the logos render correctly across all breakpoints.
