01 — Scope

What Gets Built

Full breakdown of every deliverable — no vague line items.

01
WordPress + WooCommerce Environment Setup
Configure the provided hosting (PHP, MySQL, SSL). Install WordPress, WooCommerce, child theme. Harden security (limit login, firewall plugin, HTTPS enforce). Configure caching (LiteSpeed or W3TC) and CDN.
WooCommerce 8.x Hostinger/SiteGround SSL + Hardening
02
Theme — Amazon-Style UI/UX
Implement a clean, dense product-catalog theme (Astra / Flatsome / custom starter). Category sidebar with nested phone model filters, parts-type filters, price range. Breadcrumb navigation, sticky header with search, mobile-first responsive grid.
Astra Pro / Flatsome Elementor or Gutenberg blocks WCAG AA
03
AliExpress Product Import — 3,000 SKUs
Use DSers or AliDropship Chrome extension + WooCommerce plugin to bulk-import 3,000 products. Map categories: Phone Screens, Batteries, Back Covers, Charging Cables, Cases, Accessories. Optimise import pipeline to preserve variation data (color, size, model).
DSers Plugin AliDropship CSV Fallback Variation Support
04
German Localization — High-Quality
Translate product titles and descriptions into clean, natural German. No raw DeepL dump — post-edit every product description for grammar, terminology, and tone (Swiss-German commerce norms). Use WPML + WooCommerce Multilingual for site-wide localization. Configure CHF currency, Swiss date/number formats.
WPML WooCommerce Multilingual DeepL API + Human Post-Edit CHF Currency
05
Product Image Optimization
Download and rehost all product images on the client's server (no hotlinking to AliExpress). Convert to WebP, compress without quality loss, generate srcset for responsive delivery. Add lazy-loading. Target: core web vitals LCP <2.5s.
WebP Conversion ShortPixel or Imagify Lazy Load LCP Target <2.5s
06
On-Page SEO — Full Implementation
Rank-Math or Yoast SEO setup. Optimized meta titles and descriptions per product (German). Schema markup: Product, BreadcrumbList, Organization. Canonical URLs, XML sitemap, robots.txt. Structured category pages with H1/H2 hierarchy. Submit to Google Search Console.
Rank Math SEO Schema.org Markup Google Search Console
07
Swiss Marketplace Integration
Connect WooCommerce to Galaxus (Digitec) and Ricardo via their seller API or a feed plugin (Lengow, Channable, or WooCommerce Google Feed Manager). Generate compliant product feeds (GTIN/EAN, CHF pricing, German descriptions). Inventory sync to avoid overselling.
Galaxus Seller API Ricardo.ch Lengow / Channable Feed GTIN Required
08
Advanced Product Filtering
Implement AJAX-powered filtering by: Phone Brand → Phone Model → Part Type → Price Range → Condition → Compatibility. Use FiboFilters or WooCommerce Product Filters plugin. Filtered URLs must be indexable (no JS-only param rendering) for SEO.
FiboFilters AJAX Filtering SEO-Friendly URLs
09
Payment + Checkout (Swiss Market)
Configure WooCommerce payments appropriate for Switzerland: Stripe (VISA/MC), PostFinance (optional), TWINT (if available via gateway), PayPal. Configure VAT/MWST handling (Swiss 8.1%), shipping zones for CH/DE/AT. GDPR-compliant checkout with cookie banner.
Stripe TWINT Gateway Swiss VAT 8.1% GDPR Cookie Banner
10
Automated AliExpress Order Fulfilment
Set up DSers semi-automated order fulfilment workflow: WooCommerce order → DSers one-click push to AliExpress supplier → auto tracking number pull-back → email customer. Configure pricing rules (2.5× cost multiplier for CHF). Set up price auto-update when supplier changes cost.
DSers Automation Tracking Integration Pricing Rules

06 — Risks & Caveats

Important Considerations

These need client acknowledgement before project start.

Galaxus Seller Account Required
Galaxus/Digitec has a manual seller onboarding process. Client must have an approved seller account. Integration cannot proceed without this.
GTIN / EAN Codes for Marketplaces
Ricardo and Galaxus require valid GTINs/EANs for most categories. Phone parts from AliExpress often lack proper GTINs — this may limit which products are listable.
German Translation Volume
3,000 descriptions post-edited to natural German is significant scope. Allocated budget assumes avg. 50-word descriptions. Longer product copy or custom rewriting is outside scope.
All Premium Plugins Included — Zero Licence Cost to Client
WPML, Rank Math Pro, FiboFilters, ShortPixel, Channable, Astra Pro, and all required premium plugins are covered under an enterprise unlimited licence. No additional plugin costs are passed to the client — ever.
AliExpress Product Quality Variation
Supplier quality, shipping times, and stock vary. DSers can sync price/stock but cannot guarantee supplier reliability. A supplier vetting step is recommended before go-live.
TWINT Payment Gateway
TWINT requires a Swiss business bank account. If client does not have one, this gateway must be skipped. Stripe + PayPal covers most Swiss buyers regardless.

The biggest risk on this project is not the technical build — it's the translation volume and marketplace onboarding. Nail those two, and the store launches to a fully indexed, market-ready catalog on day one.

3,000 product descriptions post-edited to natural, commerce-grade German is the single most time-intensive task — and the one most agencies cut corners on with raw machine output. Getting it right means every product is findable, trustworthy, and conversion-ready from launch. Marketplace onboarding on Galaxus and Ricardo requires seller approval, valid GTIN data, and compliant CHF product feeds — none of which can be rushed on the client's side. These two non-technical dependencies are the real project timeline drivers.

That alone represents $400–600/yr in tools included at no additional charge. Combined with the advanced SEO build, AJAX filtering, and automated DSers fulfilment pipeline, this is a production-grade store at a fraction of standard agency rates.
