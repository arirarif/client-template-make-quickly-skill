## 1. What we are building

A logged-in customer portal inside the BizJump WordPress site that gives each customer a single place to:

- See the status of their business formation
- Access all their business documents
- Track compliance deadlines (annual reports, taxes, state filings)
- Manage active services and add new ones
- Follow a step-by-step action plan to set up their business
- Message the BizJump team
- Edit their business profile

It replaces the default WooCommerce **My Account** experience with a dedicated dashboard.

## 2. In-scope deliverables (v1)

### 2.1 Seven customer-facing sections

| # | Section | Core function |
|---|---|---|
| 1 | Dashboard Home | Business status card + quick actions checklist + summary panel |
| 2 | Document Hub | Per-customer document list with status tags + upload/download |
| 3 | Compliance Center | Alerts + monthly calendar with color-coded deadlines |
| 4 | Service Management | Active services + available add-ons + upgrade flow |
| 5 | Action Center ⭐ | Tabbed checklist (Setup / Growth / Compliance) — **key differentiator** |
| 6 | Communication Hub | Threaded messages with BizJump team + file attachments |
| 7 | Business Profile | Editable business details (name, entity, state, EIN, agent, etc.) |

### 2.2 Four global UI elements

| # | Element | Notes |
|---|---|---|
| 8 | Sidebar | 8 menu items with active state |
| 9 | Top Bar | Logo + bell + Support button + account menu |
| 10 | Notifications System | In-app bell + email triggers (filing, EIN, deadlines, messages, documents) |
| 11 | Support Access | Persistent "Contact Support" button on every page |

### 2.3 Empty-state copy

For Documents, Compliance, Services (3 strings — see master doc §10).

### 2.4 Status / data fields

- Business: name, entity type, state, formation date, EIN, registered agent
- Filing status: Preparing → Filed → Approved
- EIN status: Not Started / In Progress / Completed
- Document statuses: Ready (green) / Pending (yellow) / Processing (blue)
- Compliance statuses: On Track (green) / Action Required (yellow) / Overdue (red)

## 4. Out of scope (v1)

Stating these explicitly so they don't drift in:

- Mobile native app (web-responsive only)
- Multi-business per account (one business per customer)
- Public-facing marketing redesign (already exists; only My Account changes)
- Self-service legal document generation (Phase 2 — Gravity PDF + eSignature)
- Gamification / badges (Phase 2 — GamiPress)
- Advanced loyalty / coupon engine (Phase 2)
- Multi-language / i18n
- White-label / agency mode
