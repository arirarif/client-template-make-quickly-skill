How to link COAs to products

Deployment Recipe.

  1. Bulk-upload the 20 PDFs to WP Media Library (Media → Add New → drag the whole pep/03/ folder in).
  2. For each product (Products → edit), scroll to the Product Data → Atomic Blue Specs meta box (already wired in functions.php).
  3. Set the _pp_coa_url field to the matching PDF's media URL.
  4. Product page renders the "📥 Download COA" button automatically (via the existing pp_atomic_pdp_specs hook).
  5. For the 31 products WITHOUT a COA, leave _pp_coa_url empty — the button is hidden, replaced by a softer "COA available on request →" link.

Optional · Auto-attach by SKU

Auto-Match Script.

Run this WP-CLI one-off command (or paste into a temporary snippets plugin then delete) to auto-match each COA filename to the product with the matching SKU/title. Saves ~20 minutes of clicking.

// Drop into functions.php, visit /?run-coa-import=1 once, then DELETE.
add_action('init', function() {
    if ( ! isset($_GET['run-coa-import']) || ! current_user_can('manage_options') ) return;

    $map = [
        'AOD-9604'     => 'Performance_Peptides_COA_AOD_9604_5MG.pdf',
        'BPC-157'      => 'Performance_Peptides_COA_BPC_157_10mg.pdf',
        'CJC-1295-DAC' => 'Performance_Peptides_COA_CJC_1295_With_DAC_5mg.pdf',
        // ... add the other 17 compound-name → filename pairs
    ];

    foreach ( $map as $sku => $coa_file ) {
        $product = wc_get_product( wc_get_product_id_by_sku($sku) );
        if ( ! $product ) continue;
        $coa_url = home_url('/wp-content/uploads/coas/' . $coa_file);
        update_post_meta( $product->get_id(), '_pp_coa_url', $coa_url );
        echo "✓ Linked $sku to $coa_file<br>";
    }
    exit;
});
