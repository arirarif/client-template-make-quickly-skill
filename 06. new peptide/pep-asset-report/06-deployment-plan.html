Job 1 · ~20 minutes · Highest impact

Auto-Inject 01 + 04.

PRIORITY 1

Hook into WooCommerce's product gallery filter and inject the reconstitution guide + disclaimer onto every product page automatically — no manual upload per product.

📁 File to edit: 02-woodmart-child/functions.php

/* =====================================================================
   Auto-inject the on-brand reconstitution guide + disclaimer poster
   into every product gallery. Hooks into WooCommerce's gallery filter
   so the images appear right after the product's own photo.

   Setup: upload pep/01.png and pep/04.png to Media Library, then
   replace the two attachment IDs below.
   ===================================================================== */
add_filter( 'woocommerce_single_product_image_gallery_classes', '__return_value', 10 );

add_filter( 'woocommerce_product_get_gallery_image_ids', 'pp_atomic_pdp_brand_images', 10, 2 );
function pp_atomic_pdp_brand_images( $gallery_ids, $product ) {
    // Replace with real Media Library attachment IDs after upload.
    $reconstitution_id = 1234; // pep/01.png
    $disclaimer_id     = 1235; // pep/04.png

    // Inject brand images at the START of the gallery (right after the
    // featured image) so they're the first thing customers swipe to.
    if ( $reconstitution_id ) {
        array_unshift( $gallery_ids, $reconstitution_id );
    }
    if ( $disclaimer_id ) {
        $gallery_ids[] = $disclaimer_id; // last image
    }

    return array_unique( $gallery_ids );
}
  • Upload pep/01.png and pep/04.png to Media Library
  • Note both attachment IDs (visible in URL when editing the media)
  • Replace 1234 and 1235 with real IDs
  • Visit any product → confirm: product photo → reconstitution guide → disclaimer in gallery

Job 2 · ~30 minutes · Manual click-through OR scripted

Attach 20 COAs.

PRIORITY 2

Two paths — pick the one you prefer.

🖱 Path A · Manual (20 min)

For each of the 20 products:

  1. Open product in WP admin
  2. Scroll to Product Data → Atomic Blue Specs meta box
  3. Click "Upload COA" → pick the matching PDF
  4. Save

Pros: No code · safest · no risk of mismatched files

Cons: Repetitive · ~60s per product

⚡ Path B · Scripted (5 min)

Bulk-upload PDFs first, then run a one-off auto-match script (see full script on COA page).

  1. FTP / SFTP pep/03/ into wp-content/uploads/coas/
  2. Drop the auto-match snippet into functions.php
  3. Visit /?run-coa-import=1 once as admin
  4. Delete the snippet

Pros: 5 min total · reusable for future batches

Cons: Needs SKU mapping to be correct

Job 3 · ~15 minutes · Site-wide

Install Favicon Pack.

PRIORITY 3

Two-step: WP-managed icon via Customizer + extra <head> tags for Apple-touch + PWA support.

Step A · WP Customizer (Site Icon)

  1. Go to Appearance → Customize → Site Identity
  2. Click "Site Icon" → upload pep/02/icon-512.png
  3. WP auto-generates 16, 32, 192, 270 sizes from this one upload
  4. Publish

Step B · Extra head tags for Apple + PWA

Copy pep/02/ into 02-woodmart-child/assets/icons/, then add this to functions.php:

add_action( 'wp_head', 'pp_atomic_favicon_tags', 5 );
function pp_atomic_favicon_tags() {
    $base = get_stylesheet_directory_uri() . '/assets/icons/';
    ?>
    <link rel="shortcut icon" href="<?php echo esc_url( $base . 'favicon.ico' ); ?>">
    <link rel="apple-touch-icon" sizes="180x180" href="<?php echo esc_url( $base . 'icon-180.png' ); ?>">
    <link rel="icon" type="image/png" sizes="512x512" href="<?php echo esc_url( $base . 'icon-512.png' ); ?>">
    <link rel="manifest" href="<?php echo esc_url( $base . 'manifest.json' ); ?>">
    <meta name="theme-color" content="#071b2d">
    <?php
}

Job 4 · ~15 minutes · Visual / brand

Swap White Logo.

PRIORITY 4 · VERIFY FIRST
⛔ Block: Don't run this job until you've confirmed the white logo files actually have white pixels. See Asset 05 page for the verification recipe.
  1. Open PP ATOM WIDE LOGO white.png in image editor → eyedrop pixel → confirm #FFFFFF. If #000000, STOP and request real white from client.
  2. Upload both PNGs to Media Library.
  3. Desktop header: WoodMart → Theme Settings → Header → Logo → upload wide lockup.
  4. Mobile header: WoodMart → Theme Settings → Mobile Header → Logo → upload atom-only.
  5. Footer: Appearance → Customize → Footer Builder → Logo widget → upload wide lockup.
  6. Emails: WooCommerce → Settings → Emails → Header image → upload wide lockup.
  7. Hard-refresh on desktop + mobile + open a test order receipt to verify.
