Canadian Peptide Site
WooCommerce Enhancement Brief

Posted ~36 minutes ago · 5 responses · Fixed price · Less than 1 month · Canada

Up to $172 / delivery · 5 deliveries/day Existing WooCommerce site Payment integration SEO audit Security / malware Custom product tabs Canadian market (CAD)
What client needs — 5 clear tasks
1. Add Interac e-Transfer as a payment method
Payment
Client wants customers to be able to pay via Interac e-Transfer — a standard Canadian bank transfer method. The checkout should:
  • Show clear instructions for how to send the e-Transfer
  • Hold the order as "pending" until payment is manually confirmed
  • Fit cleanly into the existing WooCommerce checkout flow
→ Approach: WooCommerce BACS gateway (customised) or a dedicated Interac plugin. No gateway fee involved — manual confirmation flow.
2. Add 3% credit card surcharge at checkout
Payment
When a customer selects a credit card payment option, a 3% fee should be automatically added to the order total. The surcharge must be:
  • Clearly visible on the checkout page before payment is submitted
  • Applied dynamically only when credit card is selected
  • Reflected correctly in the order total and order confirmation email
→ Approach: WooCommerce Fees API or a surcharge plugin (WC Checkout Fees). Must comply with card network rules.
3. Custom product page tabs — COA & Endotoxin testing
Product Pages
Each product page needs two additional tabs (alongside Description/Reviews):
  • COA tab — Certificate of Analysis (PDF upload per product, viewable in-browser)
  • Endotoxin Testing tab — test result document (PDF upload, editable via backend)
  • Both tabs must be editable by the client without touching code
  • Must display correctly on mobile
→ Plugin: "Custom Product Tabs for WooCommerce" (client specified this). Needs per-product PDF upload field.
4. Full on-page SEO audit + implementation
SEO
Not just an audit — they want the fixes implemented too:
  • Optimise meta titles and descriptions for all key pages + products
  • Improve page speed (Core Web Vitals — LCP, CLS, FID)
  • Fix mobile performance issues
  • Schema markup review (Product, Organization)
→ Tool: Rank Math or Yoast. Page speed: image compression, caching, defer JS. Report before + after PageSpeed scores.
5. Security hardening + malware scan & cleanup
Security
The site needs a proper security layer — this is a peptide/supplement store, higher attack target:
  • Install and configure a Web Application Firewall (WAF)
  • Full malware scan of all WordPress files and database
  • Clean up any infections found
  • Harden login (rate limiting, 2FA, change default admin URL)
→ Plugin: Wordfence (WAF + scan) or MalCare. One-time deep clean + config.
Clarify before starting
⚠ Ask the client these before sending a proposal
  1. What payment gateway are they using for credit cards? — The 3% surcharge implementation differs between Stripe, Square, or PayPal. Need to know before quoting.
  2. Is there an existing Interac e-Transfer flow or should it be built from scratch? — Some peptide stores already have a manual bank transfer setup; others need a new plugin entirely.
  3. How many products have COA / Endotoxin docs that need uploading? — If it's 200+ products, that's a migration task on top of the dev work and affects timeline/price.
  4. Has the site had any known malware or hacking incidents? — If infected, cost of cleanup goes up. Good to flag upfront.
  5. "5 deliveries per day" — what does this mean for them? — This likely refers to Upwork's contract structure, not actual deliverables. Confirm it's just one full project payment split into 5 tranches of $172 ($860 total), or if they mean 5 separate scoped tasks done one at a time.
